multipass

A minimal password manager for the secrets you never want on someone else's server, such as recovery codes, seed phrases, and the master password of your everyday password manager.

curl -fsSL https://getmultipass.dev/install.sh | bash

The installer builds the tagged release from source when Rust is installed. Without Rust, it installs the prebuilt macOS binary only after gh attestation verify proves that the release workflow built it from that tag. It never touches your stores or your shell's startup files.

What it is

  • One passphrase, one small folder. Your secrets, and the setup keys of your one-time passwords, live in a small folder of files encrypted with age and unlocked by a passphrase you choose. There are no accounts and no server.
  • No dependencies. Every line is in the repository, cryptography included, small enough to read in a day. No third-party crates, so a build from source trusts only the Rust toolchain, and GitHub to serve the tagged source. The prebuilt binary also trusts GitHub's hosted macOS runner, with its Xcode linker and lipo, the pinned Rust toolchain, and GitHub's and Sigstore's signing of its attestation, which install.sh verify lets you replace with your own build. The one-liner above also trusts whoever controls this domain, its registrar account, and its Vercel team, which the commands below avoid.
  • Recoverable without it. Every file in the store is an ordinary age file, so two age -d commands print everything as plain text even if multipass disappears.

Install without this domain

This domain only redirects to releases on GitHub: /install.sh to the newest, and /v<version>/install.sh to that release. To skip it, use GitHub's URL directly:

curl -fsSL https://github.com/ninjudd/multipass/releases/latest/download/install.sh | bash

To pin a release, so a later one cannot change what you run, name its tag and its version:

curl -fsSL https://github.com/ninjudd/multipass/releases/download/v0.2.0/install.sh | MULTIPASS_VERSION=0.2.0 bash

To check the installer before you run it, download it with its attestation bundle and verify it:

curl -fsSLO https://github.com/ninjudd/multipass/releases/latest/download/install.sh
curl -fsSLO https://github.com/ninjudd/multipass/releases/latest/download/multipass.sigstore.json
gh attestation verify install.sh --bundle multipass.sigstore.json --repo ninjudd/multipass \
  --signer-workflow ninjudd/multipass/.github/workflows/release.yml --source-ref refs/heads/main
bash install.sh
